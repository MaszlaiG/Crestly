 NETTLI — FIREBASE BEÁLLÍTÁS (Authentication + Firestore + Hosting)
 Projekt: nettli-202608

MI EZ AZ APP?
  A Nettli egy személyi vagyonkezelő (arany, részvény, kripto, hitel,
  zálog, előfizetés). Minden felhasználó bejelentkezik, és KIZÁRÓLAG a
  saját adatát látja. Az adat a felhőben, Firestore-ban tárolódik,
  fiókonként egyetlen dokumentumban: vaults/{uid}. NINCS nyilvános
  űrlap — csak bejelentkezett felhasználó ír/olvas.

  Három Firebase-szolgáltatás kell:
    - Authentication → a bejelentkezés (e-mail/jelszó).
    - Firestore     → az adat tárolása a felhőben.
    - Hosting       → maga a weboldal kiszolgálása (HTTPS-sel).

4) A DEPLOY-FÁJLOK (már a mappában vannak)
----------------------------------------------------------------------
Ezek a fájlok már készen a Nettli mappájában — nem kell "firebase init":

  firebase.json          → a Hosting + Firestore beállítása (mit tölts fel).

  firestore.indexes.json → (üres) index-fájl.


----------------------------------------------------------------------
5) FIRESTORE SZABÁLYOK — MAGYARÁZAT (firestore.rules)
----------------------------------------------------------------------
Ez a VÉDELEM MAGJA. A szabály:

    match /vaults/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }

Jelentése:
  - request.auth != null  → csak BEJELENTKEZETT felhasználó.
  - request.auth.uid == uid → és KIZÁRÓLAG a SAJÁT dokumentumát
    (vaults/{a-saját-uid-ja}) írhatja/olvashatja.
  → Egyik fiók sem látja a másik pénzügyi adatát.

A szabály a "firebase deploy"-jal automatikusan felkerül (a firebase.json
tartalmazza a firestore blokkot) — nem kell a console-ban kézzel bemásolni.


----------------------------------------------------------------------
6) DEPLOY (feltöltés)
----------------------------------------------------------------------
A Nettli mappájában:

    cd "<a Nettli mappa útvonala>"
    firebase deploy

  Ez felteszi a HOSTINGOT ÉS a FIRESTORE-SZABÁLYT is.
  A végén kiírja az élő URL-t:
      https://nettli-202608.web.app
      https://nettli-202608.firebaseapp.com

  A Hosting alapból HTTPS-t ad (automatikus SSL). Minden későbbi
  módosítás után futtasd újra a "firebase deploy"-t.

  (Csak az egyik rész külön:
     firebase deploy --only hosting
     firebase deploy --only firestore:rules )


----------------------------------------------------------------------
7) DEPLOY UTÁN
----------------------------------------------------------------------
- Nyisd meg az élő oldalt (nettli-202608.web.app) → REGISZTRÁLJ egy

- Új fiók ÜRESEN indul (nincs mintaadat).


----------------------------------------------------------------------
8) (OPCIONÁLIS) EGYEDI DOMAIN
----------------------------------------------------------------------
Console → Build → Hosting → "Add custom domain" → add meg a domained
(pl. nettli.hu) → kövesd a DNS-lépéseket. Az SSL automatikus.
Utána vedd fel az új domaint: Authentication → Settings → Authorized
domains (a .web.app alapból bent van).


----------------------------------------------------------------------
9) BIZTONSÁG DIÓHÉJBAN
----------------------------------------------------------------------
- HTTPS: a Hosting adja automatikusan.
- Auth + Rules: a bejelentkezés + a uid-re zárt szabály védi az adatot.
- apiKey: a kódban lévő apiKey NEM titok (publikus azonosító); a védelmet
  az Auth + a Firestore-szabályok adják.
- App Check (bot-védelem): a Nettlinél kevésbé kritikus, mert NINCS
  nyilvános írás (csak bejelentkezett user ír). Később bekapcsolható.
- Backup: a Fiók → Export data funkcióval bármikor JSON mentés.
